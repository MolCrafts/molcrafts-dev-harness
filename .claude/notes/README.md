# .claude/notes — passive project knowledge

Internal context the agent reads to understand this repo: decisions,
conventions, contracts, debt, open questions. Outlives any single change.

- `law.md` — the inviolable rules. Outranks everything else here.
  `/mol:compact` may absorb into it, never delete from it.
- `notes.md` — evolving decisions (written by `/mol:note`).

Not here: public docs (use READMEs), active specs (`.claude/specs/`), or
Claude Code runtime config (`.claude/skills/`, `.claude/settings.json`).
See [`../../plugins/mol/rules/design-principles.md`](../../plugins/mol/rules/design-principles.md) § 1.
